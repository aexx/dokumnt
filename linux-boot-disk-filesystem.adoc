== Grub

=== grub config (debian update-grub script)


TIP: */boot/grub/menu.lst:* ...AUTOMAGIC KERNELS LIST +
DO NOT UNCOMMENT THEM, Just edit them to your needs... +
Alles innerhalb des "AUTOMAGIC KERNELS LIST" - Blocks wird vom *"update-grub script"* nach Kernel-Updates/Installationen oder per *# sudo update-grub #* neu ge(ueber)schrieben. +
Es koennen jedoch ueber die "Default Options" *dauerhafte* Anpassungen gemacht werden (die Kommentarzeichen *# nicht* entfernen) z.B.:

[source,bash]
----
# kopt=root=UUID=61e70678-eff8-494f-a085-fadcb1e723ff ro
# defoptions=vga=794 console=tty0 console=ttyS0,115200
----

TIP: Welche/which uuid: `sudo vol_id --uuid /dev/sda1`



==== GRUB4DOS cd chainloaden

.Man kann auch nach dem man GRUB4DOS gestartet hat noch nachtraeglich von CD-ROM booten. Dies ist auch moeglich wenn das BIOS schon aelter ist und eigentlich booten von CD-ROM nicht unterstuetzt. Diese Unterstuetzung ist allerdings experimentell und benoetigt weitere Tests!
----
  title Boot From First CDROM
  cdrom --init
  map --hook
  chainloader (cd0)
  boot

  title Boot From Second CDROM
  cdrom --init
  map --hook
  chainloader (cd1)
  boot
----

=== Boot ISO Images

.=> */etc/grub.d/40_custom*
[source,bash]
----
#!/bin/sh
exec tail -n +3 $0
# This file is an example on how to add custom entries

menuentry "grml-rescue sda1" {
  loopback loop (hd0,1)/iso/grml-small_2009.05.iso
  linux    (loop)/boot/grmlsmall/linux26 isofrom=/dev/sda1/iso/grml-small_2009.05.iso boot=live quiet vga=791 noeject noprompt
  initrd   (loop)/boot/grmlsmall/initrd.gz
}
menuentry "grml-rescue sdb1" {
  loopback loop (hd1,1)/iso/grml-small_2009.05.iso
  linux    (loop)/boot/grmlsmall/linux26 isofrom=/dev/sdb1/iso/grml-small_2009.05.iso boot=live quiet vga=791 noeject noprompt
  initrd   (loop)/boot/grmlsmall/initrd.gz
}

menuentry "(hd0,1) sda1" {
  set root=(hd0,1)
  chainloader +1
}
menuentry "(hd1,1) sdb1" {
  set root=(hd1,1)
  chainloader +1
}
----


IMPORTANT: Die */boot/grub/grub.cfg* sollte *nicht* editiert werden, sondern wird anhand der Konfig-Dateien unter /etc/grub.d/ per: *# update-grub* erzeugt.

== Disk Layout Backup

[source,bash]
----
$  DISKS=$(cat /etc/mtab|egrep -v "/dev/fd|/cdr|drbd|mapper|sys|none|proc|gvfs"  |awk '{print $1}' |grep /dev/|sed 's/[0-9]$_g' |sed 's/p$_g' |sort -u) ; echo $DISKS
$  for DISK in $DISKS ; do DISK_NAME=`echo $DISK |awk -F/ '{print \$3\$4}'`; echo $DISK_NAME; sudo /sbin/sfdisk -d $DISK > sfdisk.${DISK_NAME}_$(date +%Y-%m-%d) ;
$  sudo /sbin/fdisk -l > fdisk-l.${DISK_NAME}_$(date +%Y-%m-%d) ; done

----
